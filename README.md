## 📌 Tentang SEHATI-AI

**SEHATI-AI** adalah aplikasi kesehatan cerdas yang menggabungkan kecerdasan buatan (Computer Vision, Machine Learning, dan Large Language Models) untuk mendampingi pengguna dalam memantau kesehatan secara holistik. Aplikasi ini menyediakan evaluasi asupan gizi harian, analisis aktivitas fisik dan gaya berjalan (Gait Analysis), pemantauan gula darah, skrining risiko diabetes, program diet terarah, serta asisten konsultasi virtual.

## 🌟 Fitur-Fitur Utama

- **🏠 Dasbor Kesehatan Holistik**: Menampilkan metrik vital dalam satu layar, termasuk estimasi *Biological Aging Score*, skor kebugaran, asupan air harian, serta ringkasan aktivitas.
- **📷 AI Food Recognition**: Pengenalan makanan khas Indonesia dan internasional secara otomatis melalui kamera menggunakan model computer vision (YOLOv8), lengkap dengan rincian kalori dan makronutrisi.
- **🩺 Prediksi Risiko Diabetes**: Skrining klinis mandiri untuk deteksi dini risiko diabetes tipe 2 menggunakan model klasifikasi Machine Learning.
- **🩸 Tracker Gula Darah**: Pencatatan kadar glukosa darah berkala dengan kategorisasi otomatis (normal, pradiabetes, diabetes) serta visualisasi grafik tren harian/bulanan.
- **🚶 Sensor Pedometer Hemat Daya**: Penghitung langkah latar belakang (*background step tracking*) menggunakan akselerometer bawaan perangkat tanpa menguras baterai.
- **🔬 Gait Analysis (Analisis Gaya Berjalan)**: Pengukuran keteraturan cadence, simetri langkah, dan variabilitas langkah untuk indikator pencegahan penurunan fungsi fisik.
- **💪 Panduan Latihan Fisik (Workout)**: Katalog latihan terstruktur (Dada, Punggung, Kaki, Lengan, Bahu, Inti) lengkap dengan instruksi langkah demi langkah.
- **🥗 Rekomendasi Diet & Nutrisi Personal**: Rekomendasi menu harian yang seimbang berdasarkan kebutuhan kalori BMR/TDEE pengguna.
- **✨ Scan Kesehatan Kulit**: Deteksi kondisi kulit wajah (jerawat, pigmentasi) serta informasi indeks UV untuk panduan perlindungan sinar matahari.
- **💬 Asisten AI Interaktif**: Asisten virtual "Nubi" yang ramah untuk tanya-jawab seputar kesehatan, pola makan, dan olahraga.

## 🛠️ Arsitektur & Teknologi

- **Frontend**: [Flutter](https://flutter.dev/) (Dart) dengan arsitektur modular, Provider / State Management terstruktur, dan komponen kustom responsif.
- **Backend & Database**: [Supabase](https://supabase.com/) (PostgreSQL, Realtime, Row Level Security, Storage, Edge Functions).
- **Computer Vision & ML**:
  - Ultralytics YOLOv8 untuk deteksi makanan dan analisis citra
  - Model klasifikasi risiko klinis
- **Generative AI & LLM**:
  - Groq API (Llama 3 / Mixtral untuk respon ultra-cepat)
  - Google Gemini API (analisis multimodal dan konsultasi kontekstual)
- **Sensor Fusion**: Integrasi Accelerometer, Pedometer API, dan GPS untuk pelacakan rute dan gerak aktif.

## 🚀 Memulai (Getting Started)

### Prasyarat
- Flutter SDK (versi >= 3.3.0)
- Android SDK / Xcode untuk emulator atau perangkat fisik
- Akun Supabase (opsional jika menggunakan server lokal)

### Instalasi & Menjalankan Aplikasi

1. **Clone repositori:**
   ```bash
   git clone https://github.com/MuhamadHata/Aplikasi-SEHATI-AI.git
   cd Aplikasi-SEHATI-AI
   ```

2. **Pasang dependensi Flutter:**
   ```bash
   flutter pub get
   ```

3. **Konfigurasi API Keys AI (Opsional):**
   Salin file konfigurasi contoh:
   ```bash
   cp secrets/nubi_ai.example.json secrets/sehati_ai.local.json
   ```
   Isi API key yang valid, lalu jalankan:
   ```bash
   flutter run --dart-define-from-file=secrets/sehati_ai.local.json
   ```
   Atau jalankan langsung untuk mode default:
   ```bash
   flutter run
   ```
